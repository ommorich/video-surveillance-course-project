# Информационная система видеонаблюдения

## Назначение проекта
Репозиторий содержит материалы курсового проекта по разработке информационной системы видеонаблюдения. Система предназначена для управления видеопотоками, архивом записей, пользователями, ролями доступа и заявками на обслуживание оборудования.

Проект рассматривает не только техническую структуру системы, но и продуктовые метрики: активность пользователей, просмотры камер, обращения к архиву, успешные входы, созданные заявки, удержание клиентов и диагностические показатели доступности камер.

## Состав репозитория
- docs/ - проектная документация, постановка задачи, требования и методика.
- src/ - исходные файлы, прототипы или скрипты.
- data/sample/ - небольшие демонстрационные данные.
- data/raw/ - локальные исходные данные, которые не отправляются на GitHub.
- experiments/ - журнал проверок, расчетов или экспериментов.
- assets/ - изображения, схемы и диаграммы.

## План выполнения
1. Постановка задачи и анализ предметной области видеонаблюдения.
2. Описание ролей пользователей, камер, архива и заявок.
3. Разработка модели метрик и критериев успешности.
4. Подготовка прототипа структуры системы.
5. Проверка результата и оформление пояснительной записки.
