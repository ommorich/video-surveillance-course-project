# Методика работы над проектом

## Подход
Работа над курсовым проектом строится как сопровождение информационной системы в GitHub. Каждый смысловой этап фиксируется отдельным коммитом, а изменения в документации и прототипах выполняются в отдельных ветках.

## Основные шаги
1. Описать предметную область видеонаблюдения и роли пользователей.
2. Сформировать требования к онлайн-просмотру, архиву, заявкам и правам доступа.
3. Выделить метрики продукта: активные пользователи, просмотры камер, обращения к архиву, созданные заявки и удержание клиентов.
4. Проверить структуру репозитория и подготовить контрольную версию проекта.

## Оценка результата
Результат считается пригодным для продолжения разработки, если README объясняет назначение проекта, PROJECT_CARD содержит цель и задачи, docs включает постановку задачи и методику, а история Git показывает осмысленные этапы работы.
