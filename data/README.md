# Данные проекта

В этой папке хранятся только демонстрационные или обезличенные данные для проверки работы информационной системы видеонаблюдения.

- data/sample/ - небольшие примеры данных: список камер, событий движения или заявок.
- data/raw/ - локальная папка для исходных данных, не отправляется на GitHub.

Большие видеозаписи, персональные данные, реальные адреса объектов и закрытые журналы доступа не размещаются в репозитории.
